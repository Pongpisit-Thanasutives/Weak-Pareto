# Reference outputs used by the final manuscript

`branch_aware_campaign/` contains the final regenerated internal tables, figures, additive-Gaussian results, Weak-Pareto Yu-framework-comparison rows, and environment records. Its `main/` directory contains the aggregate publication tables (plus the per-run weak-row sensitivity file); the individual main-campaign discovery records and cache objects are not redistributed. Per-seed records are included for the additive-Gaussian and superunit experiments. `yu_framework_comparison/` contains the adapted neural fractional-discovery framework and optimiser-only comparison outputs.

The normalized-metric and periodic-domain corrections are included in these outputs. No smoke-test result is used as publication evidence. Absolute local paths and machine device identifiers were removed during packaging, without changing numerical values or hashes.

`diagnostics/` contains analytic-operator, nonlinear-bias, and temporal-target diagnostics. `frozen_soil/` contains derived fits; raw external records are not redistributed.
