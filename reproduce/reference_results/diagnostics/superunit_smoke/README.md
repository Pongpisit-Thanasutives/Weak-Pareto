# Superunit branch smoke results

These files record a focused software/branch-recovery smoke test for the
semi-analytic equation `D_t^1.65 u = 0.12 D_x^2 u`.  The support is fixed to one
linear term while the temporal branch, temporal order, and spatial order are
searched.  Two seeds are evaluated at 0% and 0.5% multiplicative-uniform noise.

These outputs are smoke-test evidence and are not used in the manuscript table.
The final five-seed experiment is archived separately under
`reproduce/reference_results/superunit_final/`.
