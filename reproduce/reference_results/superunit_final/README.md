# Final superunit branch/order experiment

These files are the completed five-seed results reported in the manuscript for
the semi-analytic equation `D_t^1.65 u = 0.12 D_x^2 u`. The support is fixed to
one linear term while the temporal branch, temporal order, spatial order, and
coefficient are estimated. Weak-Pareto and Strong Pareto use the same noisy
realisation for each seed and noise level.

This is a fixed-support branch/order diagnostic, not unrestricted equation
discovery. `summary.csv` contains the manuscript aggregates; `per_seed.csv` and
`per_seed.jsonl` contain the individual runs; `manifest.json` records the
protocol.
